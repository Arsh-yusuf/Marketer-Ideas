## 📌 Overview

**Marketer Ides** is a digital marketing and freelancing agency website built to showcase high-impact growth services, generate qualified client inquiries, and present in-depth marketing insights.

Designed with a modern aesthetic, responsive typography, and fast loading performance, the platform delivers an engaging experience across desktop, tablet, and mobile devices.

Official Agency Domain: [marketerideas.online](https://marketer-ideas-9gzs.vercel.app)

---

## ✨ Key Features

- **🎯 Interactive Multi-Section Architecture**: Seamless client navigation across Home, Services, About Us, In-Depth Blog, and Contact Us views.
- **💼 Comprehensive Services Suite**: Detailed breakdown of agency capabilities with transparent deliverables and instant proposal request triggers.
- **📰 Editorial Marketing Blog**: Industry-specific insights covering SEO, algorithm changes, carousel strategy, and conversion optimization with category filtering.
- **🎨 Custom Logo Branding & Upload**: Dynamic branding engine with SVG vector mark and persistent local storage upload options.
- **📩 Direct Client Inquiries**: Interactive contact form with automated service pre-selection and agency communication channels.
- **⚡ High Performance & SEO Ready**: Semantic HTML5 markup, Schema.org `ProfessionalService` JSON-LD structured data, OpenGraph tags, and custom branded SVG favicon.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.0.0 or higher (v20+ recommended)
- **npm**: v9.0.0 or higher

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Arsh-yusuf/Marketer-Ideas.git
   cd Marketer-Ideas
   ```

2. **Install project dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
